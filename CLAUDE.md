# Working on Lust

Lust is a rebrand of [Rose](https://github.com/Alban1911/Rose) (League of Legends skin changer) with its own
features: the desktop hub, Lust Offline, custom skins, the LUST client theme, Spotify, settings.
Repo: `lustmyself/Lust`. The owner writes in Turkish: answer in Turkish, keep it short, work
autonomously, and show a preview (screenshot) before publishing UI changes.

## The one rule: everything Lust changes lives in `lust/`

Every file outside `lust/` and `.github/` is regenerated from a Rose release by `lust/sync.py`.
Editing those files directly is lost on the next sync.

- `lust/overlay/` — Lust's own files, copied over Rose's tree (including this file).
- `lust/sync.py` — `EDITS` (exact text replacements in Rose's files), `REMOVE` (Rose paths Lust drops),
  core.dll byte patches (same length only). Every `old` must match exactly once.
- `lust/theme/build_theme.py` — builds the LUST client theme from Elaina (MIT); theme changes are `PATCHES` there.
- `lust/offline/build_offline.py` — builds Lust Offline (`LustOffline.exe`) from Deceive (GPL-3.0).

## Every change

```bash
python lust/sync.py refs/rose/1.4.9      # rebuild the tree (fetch the tag first, see below)
git restore assets/icon.ico               # sync rewrites it; keep Lust's
```

Then run the tests (CI runs the same):

```bash
for s in test $(for d in */; do [ -d "${d}tests" ] && echo "${d}tests"; done); do python -W ignore -m unittest discover -s $s -t . -q; done
python -m ruff check . --select E9,F63,F7,F82
```

## Shipping a release

1. Bump `lust/lust_patch.txt` (`1.4.9 44` → Lust 1.4.9.44).
2. Add the release's lines at the top of `lust/overlay/Pengu Loader/plugins/LUST-News/whats-new.json`
   (`version`, `en`, `tr`).
3. Sync, commit, push, then `gh workflow run "Follow Rose releases" -R lustmyself/Lust`
   (always pass `-R lustmyself/Lust`; `upstream` is Rose). CI builds and publishes `v1.4.9.N`.
4. Installed copies update themselves: silently while League is closed (`launcher/lust_autoupdate.py`).
   The update script that runs is the *old* version's, so an update-script fix helps from the next release on.

## A fresh machine

- Python 3.12+ (`pip install -r requirements.txt`), Node (for `node --check` on plugin JS), `gh auth login`.
- Rose's tag: `git fetch --no-tags https://github.com/Alban1911/Rose.git "refs/tags/1.4.9:refs/rose/1.4.9"`.
- `party/network/relay_config.py` (gitignored) must exist: `RELAY_URL = ""`.
- Theme sources (only to rebuild the theme), as `.github/workflows/builds-check.yml` does:
  `ElainaV4.zip` from the Elaina69/Elaina-theme release in `lust/elaina_version.txt`, and
  `https://registry.npmjs.org/elaina-theme-data/-/elaina-theme-data-<version>.tgz`; then
  `python lust/theme/build_theme.py ElainaV4.zip data.tgz` and
  `git restore "lust/overlay/Pengu Loader/plugins/LUST-Theme/assets/icon/mouse-cursor.png"`.
- Lust Offline: Deceive at the tag in `lust/deceive_version.txt`, `python lust/offline/build_offline.py <Deceive>`
  (needs the .NET SDK).

## How Lust is put together (Lust's own parts)

- Desktop hub: `launcher/lust_hub.py` (state + actions), `lust_hub_server.py` (token-protected HTTP on
  127.0.0.1:47823+), `lust_hub_web.py` (the page), `lust_hub_shell.py` (WebView2 window as
  `Lust.exe --lust-hub-window <url> --lust-parent <pid>`), `lust_hub_window.py` (Tk fallback).
- `lust_hero.py` (welcome card: Riot ID, rank, last match, LP cutoffs from replays.lol),
  `lust_media.py` (Spotify now playing: winrt + pycaw; COM must be multithreaded), `lust_spotify.py`
  (Spicetify themes), `lust_settings.py` (Settings tab, `hub-settings.json`), `lust_perf.py`
  (performance mode during a match), `lust_autoupdate.py`, `lust_cleanup.py`, `lust_rose.py`, `lust_offline.py`.
- Client side: `Pengu Loader/plugins/LUST-*` (LUST-Theme is generated by build_theme.py).

## Things that bit us

- Write multi-line patches as Python scripts with the Write tool, not shell heredocs (backslashes and
  line continuations get mangled).
- An `EDITS` entry whose replacement is empty used to be skipped; `apply_edits` handles it now, but prefer
  a short comment as the replacement.
- `EDITS` run in order: an anchor added by an earlier entry is only there for later ones.
- pywebview hands the page every public attribute of `js_api`: keep the window private (`_window`), or it
  reads WebView2 controls from the wrong thread and the window locks up.
- The client caches match history by the range asked last and shows it in its own Match History: ask for 0-19.
- Restarts keep Pengu Loader on (`pengu_loader.keep_on_for_restart`); Pengu can't be switched on while League runs.
- Never pop windows over the owner's game; test windows hidden. Never run old Lust uninstallers
  (they delete `%LOCALAPPDATA%\Lust`). Never uninstall Rose silently.
